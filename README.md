## 📁 Projects

### 🟦 01. Basic Data Exploration Using Excel

**Objective:** Explore a product dataset and extract useful insights using Excel formulas and functions.

**Key Tasks**
- Calculated total, average, minimum, and maximum product prices.
- Counted the total number of products.
- Used `IF` to classify products based on price.
- Applied `SUMIF` to calculate the total price of Electronics products.
- Used `COUNTIF` to count products priced below $100.
- Applied `LEFT`, `RIGHT`, and `MID` to extract information from Product IDs.

**📈 Key Results**

| Analysis | Result |
|:--|--:|
| 💰 Total Price | **$10,100** |
| 📦 Product Count | **34** |
| 📊 Average Price | **$297.06** |
| 🔻 Minimum Price | **$30** |
| 🔺 Maximum Price | **$1,000** |
| 💻 Electronics Total | **$8,050** |
| 🏷️ Products Below $100 | **11** |

**Skills:** Data Exploration · Excel Formulas · Conditional Logic · Text Functions · Basic Data Analysis

### 🟪 02. Data Cleaning and Transformation Using Excel

**Objective:** Improve product dataset quality by identifying inconsistencies, handling missing values, and transforming data into a structured format.

**Key Tasks**
- Identified missing prices and categories.
- Reviewed inconsistent product names, brands, and categories.
- Checked and removed duplicate records.
- Split Product IDs into separate columns.
- Combined brand and product names.
- Worked on price and date formatting.
- Addressed conditional formatting requirements.

**📋 Dataset Summary**

| Metric | Details |
|:--|:--|
| 📦 Cleaned Records | **31 products** |
| ⚠️ Missing Values | Identified and marked as `Unknown` |
| 🔍 Duplicate Records | Checks performed |
| 🔄 Data Transformation | Product IDs split into separate columns |
| 🏷️ Brand Information | Brand and product names combined |

**Skills:** Data Cleaning · Missing Value Handling · Data Standardization · Duplicate Detection · Data Transformation · Number Formatting · Conditional Formatting
