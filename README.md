# 📊 Product Data Exploration | Excel

### Turning raw product data into meaningful insights.

## 🔍 About the Project
A hands-on data exploration project using Microsoft Excel to uncover product pricing patterns, evaluate category-level performance, and transform Product IDs into structured information.

## ⚙️ Analysis Performed
- **Pricing Insights:** Evaluated total, average, minimum, and maximum product prices.
- **Price Segmentation:** Classified products into High Price and Standard Price categories using `IF`.
- **Category Analysis:** Calculated Electronics revenue totals using `SUMIF`.
- **Price Filtering:** Identified products priced below $100 using `COUNTIF`.
- **Data Transformation:** Extracted Day, Month, and Country Code from Product IDs using `LEFT`, `MID`, and `RIGHT`.
